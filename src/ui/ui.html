    Assumptions & method
      • Peak RPM = users × requests/user/min × peak × growth. Peak RPS = Peak RPM ÷ 60.
      • Required TPM = Peak RPM × rate-limit tokens per request. Headroom values divide by target utilization.
      • Utilization = requirement ÷ effective quota. The bottleneck is the dimension with the higher utilization.
      • Theoretical max RPM = min(TPM ÷ rate-limit tokens per request, RPM). This is a quota ceiling, not achieved throughput.
      • Shortfall = max(0, required with headroom − effective quota).
